## Règle importante : cibles des pull requests

Ce dépôt est un fork de `latent-spaces/brag`. Toute pull request doit cibler
`scalesuiteqc/scalesuite-video`, branche `main`, **jamais** `latent-spaces/brag`.

- Au début de chaque session : `gh repo set-default scalesuiteqc/scalesuite-video`
- Pour ouvrir une PR : `gh pr create --repo scalesuiteqc/scalesuite-video --base main`
